# Unified Model Directory

This directory is generated by **`scripts/build_unified_model.py`** and contains the
single-file consolidated deployment artifacts for the Bharat AI-SoC waste detection system.

## Artifacts

| File / Directory | Description |
| :--- | :--- |
| **`c2s_waste_ensemble.pt`** | Unified PyTorch checkpoint — all 10 specialist models packed into one file. Loaded with `torch.load()`. |
| **`onnx/`** | Per-specialist ONNX files + manifest JSON for ONNX Runtime / TensorRT / OpenVINO deployment. |
| **`build_report.json`** | Build timestamp, model count, sizes, and flags used at build time. |

## Loading the Unified .pt

```python
import torch
ckpt  = torch.load("models/unified/c2s_waste_ensemble.pt", map_location="cpu", weights_only=False)
model = ckpt["model"]          # EnsembleWasteDetector
meta  = ckpt["metadata"]       # dict: version, imgsz, model_roles, ...
print(model)                   # EnsembleWasteDetector(v1.0.0, models=10, categories=7)
```

Or use the high-level drop-in wrapper in `src/unified_detector.py`:

```python
from src.unified_detector import UnifiedWasteDetector
det     = UnifiedWasteDetector.from_pt("models/unified/c2s_waste_ensemble.pt")
results = det.detect(frame)    # BGR numpy frame
frame   = det.draw(frame, results)
```

## Loading via ONNX Runtime

```python
from src.unified_detector import UnifiedWasteDetector
det = UnifiedWasteDetector.from_onnx(
    "models/unified/onnx/",
    providers=["CUDAExecutionProvider", "CPUExecutionProvider"],
)
results = det.detect(frame, conf=0.25)
```

## Rebuilding

```bash
# PT only (no network required)
python scripts/build_unified_model.py --skip-onnx

# PT + ONNX (requires: pip install onnx onnxruntime onnxslim)
python scripts/build_unified_model.py --imgsz 640 --device cuda

# Help
python scripts/build_unified_model.py --help
```

> **Note:** The `.pt` / `.onnx` binary files are excluded from Git tracking
> (`.gitignore: *.pt, *.onnx`) to avoid large binary bloat.
> Run the build script after cloning to regenerate them from the specialist weights.
